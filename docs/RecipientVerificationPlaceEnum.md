# RecipientVerificationPlaceEnum

Specifies when a recipient must complete the verification process: - `before_open` (before opening the document), - `before_sign` (before signing the document). 

## Enum

* `BEFORE_OPEN` (value: `'before_open'`)

* `BEFORE_SIGN` (value: `'before_sign'`)
